# Guilds

A character without a guild can talk to the guild master npc in Devias to
create one after reaching level 100. The client asks for a name and an emblem.
Players request membership through the guild command; the guild master accepts
or declines the request. Guild members can chat with the `@` prefix.

The guild master manages member positions and can remove members or disband
the guild. Members can leave through the guild window. These actions may ask
for the account security code; an account without a security code uses its
account password. Disbanding clears the guild membership of online members and
notifies their clients immediately, so they do not need to log in again to
leave the deleted guild.

The optional [gens restrictions](gens.md#parties-guilds-and-alliances) can require
guild creators and new members to belong to the same gens. They are disabled
by default.
